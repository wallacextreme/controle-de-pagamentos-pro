# PLANO OFICIAL DE TESTES

## Objetivo

Toda alteração no projeto deve ser validada por meio deste plano de testes antes de ser considerada concluída.

---

# TESTES FUNCIONAIS

☐ O sistema inicia normalmente.

☐ Nenhum erro aparece no Console do navegador.

☐ A interface permanece igual à versão anterior.

☐ Não existem travamentos.

---

# TESTES DE CADASTRO

☐ Novo registro pode ser criado.

☐ Dados são gravados corretamente.

☐ Os dados permanecem após fechar e abrir o sistema.

---

# TESTES DE EDIÇÃO

☐ Registro pode ser editado.

☐ Alterações permanecem gravadas.

---

# TESTES DE EXCLUSÃO

☐ Registro pode ser excluído.

☐ Apenas o registro selecionado é removido.

---

# TESTES DE PESQUISA

☐ Todos os filtros continuam funcionando.

☐ Busca retorna resultados corretos.

---

# TESTES DE COMPARATIVO

☐ Comparativo continua funcionando.

☐ Todos os bancos aparecem corretamente.

---

# TESTES DE BACKUP

☐ Exportação executada com sucesso.

☐ Arquivo gerado corretamente.

☐ Importação restaura os dados corretamente.

---

# TESTES DO INDEXEDDB

☐ Bancos existentes permanecem intactos.

☐ Nenhum registro foi perdido.

☐ Nenhuma Object Store foi alterada.

---

# TESTES PWA

☐ Aplicação continua instalável.

☐ Service Worker continua funcionando.

---

# TESTES TAURI

☐ Aplicação abre normalmente.

☐ Persistência continua funcionando.

---

# TESTES DE REGRESSÃO

☐ Nenhuma funcionalidade antiga deixou de funcionar.

☐ Nenhum comportamento inesperado foi identificado.

---

# APROVAÇÃO

Uma implementação somente poderá ser considerada aprovada após todos os testes acima serem concluídos com sucesso.
