# CONTROLE DE PAGAMENTOS PRO

## Descrição

Sistema de gerenciamento de pagamentos desenvolvido em HTML5, JavaScript e TailwindCSS.

O projeto foi desenvolvido para funcionar localmente utilizando IndexedDB como banco de dados principal.

O sistema possui funcionamento Offline First e pode ser utilizado como PWA e também através do Tauri.

---

## Objetivo

Controlar pagamentos de múltiplos bancos de dados independentes, mantendo alta performance, segurança dos dados e retrocompatibilidade entre versões.

---

## Tecnologias

- HTML5

- TailwindCSS
- IndexedDB
- PWA
