# FLUXO OFICIAL DE DESENVOLVIMENTO

## Objetivo

Todo desenvolvimento neste projeto deve seguir obrigatoriamente o fluxo abaixo.

Este fluxo deve ser respeitado por desenvolvedores humanos e por Inteligências Artificiais.

---

# ETAPA 1

Ler toda a documentação existente na pasta /docs.

Nenhuma alteração pode ser iniciada antes disso.

---

# ETAPA 2

Analisar completamente a solicitação do usuário.

Identificar exatamente o que deverá ser implementado.

Nunca assumir requisitos não informados.

---

# ETAPA 3

Identificar todas as funções que poderão ser afetadas.

Explicar o motivo de cada alteração.

Não escrever código nesta etapa.

Aguardar aprovação do proprietário do projeto.

---

# ETAPA 4

Após aprovação, implementar somente a funcionalidade solicitada.

Modificar apenas os trechos necessários.

---

# ETAPA 5

Utilizar exclusivamente o modo PATCH.

Nunca reescrever arquivos completos.

Nunca reorganizar o projeto.

---

# ETAPA 6

Após a implementação realizar uma revisão completa.

Verificar possíveis regressões.

Confirmar que nenhuma funcionalidade existente foi comprometida.

---

# ETAPA 7

Executar o checklist oficial do projeto.

Somente considerar a implementação concluída após validar todos os itens.

---

# ETAPA 8

Registrar alterações relevantes no arquivo CHANGELOG.md.

---

# Objetivo Final

Garantir evolução contínua do sistema sem perda de estabilidade, compatibilidade ou dados.
